# portfolio

## 利息計算アプリ

### 概要

定期預金を想定した利息計算アプリです。<br>
元本と利率を入力し、預入期間を選択すると、税引き後の利息を計算できます。<br>
備考の入力欄を設け、入力した内容をCSVファイルに保存することができます。<br>

### 使用技術

・Python<br>
・Tkinter<br>
・CSV<br>

### 主な機能

・元本の入力<br>
・利率の入力<br>
・預入期間の選択（ボタン）<br>
・税引き後利息の計算<br>
　※税率20.315%で計算。<br>
・備考の入力<br>
・計算結果のCSV保存<br>
・入力内容のクリア<br>
・数値入力時のエラー表示<br>

### CSV保存

「保存」ボタンを押すと、入力内容を `interest_record.csv` に保存します。

保存される項目は以下。

・元本<br>
・利率<br>
・期間<br>
・税引き後利息<br>
・備考<br>

### 開発目的

アプリ開発を通して、以下の機能を実装することを目的として制作しました。

・Tkinterを使用したGUIの作成<br>
・ユーザーからの入力値の取得<br>
・入力値のエラー処理<br>
・条件分岐による計算処理<br>
・CSVファイルへのデータ保存<br>
